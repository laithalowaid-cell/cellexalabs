# Cellexa Labs website

This is the code for cellexalabs.com. You can change anything on the site by asking Claude in plain English.

## First-time setup

You need:

- A [Claude](https://claude.ai) plan that includes Claude Code
- A [GitHub](https://github.com) account, where the code is stored
- A [Vercel](https://vercel.com) account, which runs the live website

Your handover contact will help move the code and domain into your accounts.

Then:

1. Install the Claude desktop app and open its **Code** tab.
2. Choose this project folder.
3. Send this message:

   > Set this project up on my computer and show me the site running. Install anything that's missing and explain each step.

## Making changes

Tell Claude what you want. For example:

- "Change the price of Retatrutide 20 mg to 849 AED."
- "Add a new product called X with these doses and prices." (attach the photos)
- "Make a bundle with these two products for 1,200 AED."
- "Change the free delivery minimum to 1,500 AED."
- "Change the WhatsApp number to +971 ..."

Claude will show you the change on your computer first. When you're happy, say:

> Publish this to the live site.

The site usually updates within a few minutes.

## If something goes wrong

Tell Claude what you see, or say:

> Undo the last change and put the live site back how it was.

Every published version is saved in GitHub and Vercel, so earlier versions can be restored.

## Good to know

- **Orders** arrive on WhatsApp. The website doesn't take payments or keep a list of orders.
- **Keep passwords and API keys out of chat and out of the code.** If a new feature needs one, ask Claude for the safe way to add it.
- **Legal pages:** Claude can edit the wording, but have a qualified UAE lawyer review your terms, privacy policy and compliance pages.
